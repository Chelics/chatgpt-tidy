# ChatGPT Tidy

为 ChatGPT 网页添加问题目录和项目显示管理的轻量 Chrome 扩展。

长对话中，点击目录回到之前的提问；侧栏项目较多时，隐藏暂时不需要的项目，并随时恢复。

[安装](#安装) · [使用](#使用) · [隐私说明](docs/privacy.md) · [开发指南](docs/development.md) · [更新日志](CHANGELOG.md)

## 功能

- **问题目录**：自动列出当前对话中已识别的提问，点击跳转到对应位置。
- **全文预览**：悬停或键盘聚焦目录项时查看完整提问，支持滚动与文字选择。
- **项目管理**：按名称搜索项目，隐藏暂时不需要的项目，在「已隐藏」分组中恢复或打开。
- **本地保存**：保存项目隐藏状态和面板收起状态。隐藏不会删除或归档服务器上的项目。
- **外观适配**：支持浅色与深色模式，导航面板可收起。

扩展无需 API Key、独立服务器或付费服务。安装后直接在 `https://chatgpt.com/` 运行。

## 安装

当前通过 Chrome 的「加载已解压的扩展程序」安装。

1. 在本仓库页面点击 **Code → Download ZIP**，下载并解压源码。
2. 在 Chrome 地址栏打开 `chrome://extensions`。
3. 打开右上角的 **开发者模式**。
4. 点击 **加载已解压的扩展程序**。
5. 选择解压后的 `chatgpt-tidy` 子文件夹，其中包含 `manifest.json`。不要选择仓库根目录。
6. 打开或刷新 ChatGPT 网页，右侧出现「导航」按钮即表示扩展已加载。

安装与使用扩展无需运行 `npm install`，也无需构建。

### 更新或卸载

更新时，用新版本替换原扩展文件夹中的文件，在扩展管理页点击扩展的重新加载按钮，再刷新 ChatGPT 页面。保留原安装目录，可避免因重新安装造成设置丢失。

停用或卸载扩展后，项目按网页原本的方式显示。卸载会清除扩展保存的本地设置。

## 使用

### 浏览对话目录

打开「导航」中的「对话目录」，点击任意提问跳转。将鼠标停在提问上，或使用键盘聚焦该项，即可展开全文预览。按 `Esc` 关闭预览。

目录会随着新提问和已加载历史更新。已识别的提问即使被网页暂时移出页面结构，也会保留在本次打开的目录中。切换对话或刷新页面后，目录重新生成。

### 隐藏与恢复项目

打开「项目」页，在「显示中」分组点击项目旁的「隐藏」。在「已隐藏」分组点击「恢复」，项目会重新显示。点击隐藏项目的名称仍可打开该项目。

支持的侧栏项目行也会在悬停或键盘聚焦时显示减号按钮。若项目较多，可在插件的项目页按名称搜索。

隐藏状态仅作用于当前 Chrome 配置文件。同一配置文件内切换 ChatGPT 账号时，扩展设置仍会保留，项目通过 ID 区分。多个标签页同时修改设置时，以最后保存的设置为准；其他标签页收到提示后刷新即可同步。

## 隐私与权限

扩展仅匹配 `https://chatgpt.com/*` 页面，并声明 `storage` 权限，用于保存本地设置。

- 问题正文在当前页面内存中用于生成目录和预览，不写入扩展持久存储。
- 本地存储包含隐藏项目的 ID、名称、路径、面板收起状态，以及旧版本兼容所需的识别规则。
- 当前扩展源码不包含遥测、分析服务或主动向外部服务器发送数据的网络请求。

完整说明见 [隐私与数据说明](docs/privacy.md)。开发测试使用的 npm 依赖不随扩展安装。

## 兼容性与限制

目标环境为桌面 Chrome 中的 ChatGPT 网页。扩展依赖网页结构，ChatGPT 页面更新可能导致目录或项目识别失效。

- 目录只能收录本次打开后识别过的提问。尚未加载的历史提问需要先滚动加载。
- 点击已被网页卸载的提问时，扩展会尝试滚动恢复目标；无法恢复时会提示手动滚动后重试。
- 没有稳定消息标记时，完全相同的重复提问可能无法准确区分。
- 项目列表只能识别网页已经加载的项目，无法读取服务器上的完整项目清单。
- 跨域 iframe 和封闭 Shadow DOM 中的内容不受支持。

自动测试覆盖模拟网页中的主要流程，不能替代真实登录页面的兼容性验证。当前仓库未声明覆盖所有 ChatGPT 账号、页面版本或其他浏览器。
