# 隐私与数据说明

本说明对应仓库中当前版本的扩展实现。

## 运行范围

扩展通过 content script 在 `https://chatgpt.com/*` 页面运行，读取页面中可访问的提问内容和项目结构，用于构建问题目录、全文预览和项目列表。

扩展不调用 ChatGPT 服务端接口，不删除、归档或修改服务器上的项目与对话。点击项目链接时，浏览器会按正常网页导航打开 ChatGPT 项目。

## 数据存储

| 数据 | 保存位置 | 用途 |
| --- | --- | --- |
| 已识别提问的正文与目录记录 | 当前页面内存 | 目录展示、全文预览和跳转 |
| 隐藏项目的 ID、名称及相对路径 | `chrome.storage.local` | 刷新后继续隐藏，提供恢复与打开入口 |
| 面板收起状态 | `chrome.storage.local` | 保留显示偏好 |
| 面板悬浮位置 | `chrome.storage.local` | 恢复拖动后的位置 |
| 最近最多 20 条匿名运行轨迹 | 当前页面 DOM 的 `data-cgt-trace` 属性 | 本地诊断目录阶段、节点计数及切换事件 |
| 旧版本保存的提问识别规则 | `chrome.storage.local` | 兼容旧设置，必要时自动拓宽匹配规则 |

问题正文不写入扩展持久存储。切换对话会清空当前目录，刷新或关闭页面后内存记录不保留。项目设置按 Chrome 配置文件保存，不按 ChatGPT 登录账号隔离。

运行轨迹不包含提问正文、项目名称或真实路径与对话 ID，不自动发送。网页自动调整地址时，旧目录可能暂时作为不可跳转的显示快照保留，待新目录稳定后整体替换。

## 权限与网络

Manifest 声明 `storage` 权限以保存本地设置，并将页面匹配范围限定为 `https://chatgpt.com/*`。

当前扩展运行代码不包含遥测、第三方分析 SDK、广告代码或主动对外发送数据的网络请求。扩展不需要 API Key 或独立服务器。仓库中的 npm 依赖仅用于开发测试，不包含在扩展运行文件中。

## 清除数据

在项目页点击「恢复」可移除对应项目的隐藏记录。卸载扩展会清除其本地存储。停用扩展后，其本地隐藏效果停止，但已保存设置仍可在重新启用后使用。

## 问题反馈

扩展不会自动上传诊断信息。提交 Issue、截图或 HTML 片段属于你主动公开的信息，请在提交前移除个人及对话数据。
